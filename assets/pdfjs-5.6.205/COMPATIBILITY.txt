Downloaded and verified against the release asset digest on 2026-11-19.
The same files are used in vue/assets/pdfjs-5.6.205.

The compatibility build supplies JavaScript polyfills needed by browsers
that do not yet implement Map.getOrInsertComputed. Original Apache-2.0
copyright and license notices are retained in the distributed modules.
The version of the API and worker remains identical. Existing fonts,
character maps and WebAssembly assets remain those of version 5.6.205.
